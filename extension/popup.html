How to use:
1. Highlight any order text on WhatsApp, Telegram Web, or any Panel.
2. Right-click the highlighted text.
3. Select "Send as Order to Dashboard".
The order will be automatically parsed, saved, and forwarded!

Token: use the value of EXTENSION_API_KEY from the server's .env file — not your admin login password. This key doesn't expire, unlike the dashboard login token.
